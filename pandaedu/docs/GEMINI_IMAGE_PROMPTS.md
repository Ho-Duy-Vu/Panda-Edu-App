# 🎨 Gemini Image Generation Prompts for Voice Flashcards App

## 📋 Thông tin chung cho tất cả ảnh

**Style Guide:**
- Art style: Cute, friendly, child-appropriate (for ages 5+)
- Character: Baby panda (round, chubby, adorable)
- Color scheme: Matcha green (#A8D5BA, #6BBF59), Milk white (#F9FDF7), Black (#2E2E2E)
- Background: Transparent or light matcha green gradient
- Resolution: 512x512 pixels (except app_logo: 1024x1024)
- Format: PNG with transparency
- Mood: Encouraging, positive, educational, non-threatening

## 4️⃣ PANDA_SAD.PNG (512x512)

### Prompt for Gemini:

```
Create an encouraging, gently sad baby panda illustration for showing incorrect quiz answers - MUST be supportive, NOT discouraging.

Requirements:
- Size: 512x512 pixels, PNG with transparent background
- Style: Cute, empathetic, gentle - NOT scary or harsh
- Character: Baby panda sitting down
- Panda expression: Mildly disappointed but still cute and hopeful
- **CRITICAL:** This must be ENCOURAGING, not punitive. Kid should feel "try again!" not "you failed"
- Facial features:
  - Eyes: Slightly droopy but not crying, still open and gentle
  - Eyebrows: Slightly upward/worried but soft
  - Mouth: Small pout, not crying - just "oops" expression
  - NO TEARS - this is important for child psychology
- Pose: Sitting, one paw scratching head (thinking gesture)
- Body language: Thoughtful, "let's try that again" feeling
- Additional elements:
  - Small thought bubble with a light bulb (idea symbol)
  - Maybe tiny question mark (?) near head
  - Optional: Small orange/yellow "try again" badge
  - Soft, supportive vibe
- Background: Transparent
- Color palette:
  - Panda: Black (#2E2E2E) and white (#F9FDF7)
  - Cheeks: Very light pink (barely visible)
  - Thought bubble: Soft orange or light yellow
  - Question mark: Orange (#FFA726)
- Composition: Centered, grounded (sitting stable)

Art style: Gentle, supportive, educational. Inspired by growth mindset - mistakes are learning opportunities.

Mood: "Oops, let's try again!" NOT "You're wrong and should feel bad." The panda is encouraging the child to persevere. Gentle, patient, supportive teacher vibe.

**IMPORTANT:** Avoid any elements that could make a 5-year-old feel bad. This is about learning, not punishment.
```

## 🚀 GENERATION WORKFLOW

### Step-by-step with Gemini:

1. **Go to Google AI Studio** (https://aistudio.google.com/)

2. **Select Imagen model** for image generation

3. **For each image:**
   - Copy the detailed prompt (or shorter version)
   - Paste into Gemini
   - Click Generate
   - Review result
   - If not satisfactory, refine prompt with specific feedback

4. **Refinement tips:**
   ```
   If too complex: "Make simpler, more minimalist"
   If not cute enough: "Make rounder, bigger eyes, more kawaii style"
   If colors off: "Use exact colors: matcha green #A8D5BA, panda black #2E2E2E"
   If expression wrong: "Make expression more [happy/gentle/encouraging]"
   If composition off: "Center the panda more, make it larger"
   ```

5. **Download images** in highest quality available

6. **Post-processing:**
   - Resize to exact dimensions if needed (1024x1024 or 512x512)
   - Ensure transparency is preserved
   - Optimize file size with TinyPNG or similar
   - Test at different sizes (48px, 128px, 512px) to ensure clarity

7. **Place in project:**
   ```bash
   assets/images/
   ├── app_logo.png
   ├── panda_placeholder.png
   ├── panda_happy.png
   ├── panda_sad.png
   ├── panda_wave.png
   ├── panda_mic.png
   └── panda_books.png
   ```

- **Consistency is key:** All 7 images should look like they're from the same app
